# 1. 指示 — いつも守ってほしい約束ごと

## これは何

リポジトリのいちばん上に `AGENTS.md` というファイルを置くと、エージェントは会話を始めるたびに最初にそれを読みます。
新しくチームに入った人に渡す「このリポジトリの約束ごとメモ」と同じものです。

`AGENTS.md` は Copilot 以外の多くのエージェントも読む共通の名前なので、まずはこれ 1 つで足ります。

## 例

```markdown
# このリポジトリの約束

- ビルドは `cmake --build build`、テストは `ctest --test-dir build`。両方通ってから「完了」と言う。
- 返事は日本語で。
- コミットはしない。人が確認してからする。
- 分からないことは推測で進めず、質問する。
```

## 作り方: エージェントに頼む

```text
このリポジトリを読んで、AGENTS.md の下書きを作って。
ビルドとテストのコマンド、触ってはいけない場所、報告のしかたを短く。20 行以内で。
```

出てきた下書きを読んで、違うところだけ直します。

## 効いているか確かめる

**新しい会話**を開いて、約束に反することを頼んでみます(例: 「コミットして」)。断られたら効いています。

> ファイルを直したら、新しい会話で試してください。開いたままの会話には反映されません。

## コツは 3 つ

- **短く。** 毎回読まれるので、長いほど遅く・高くなります。
- **「いつも」のことだけ。** 「〜するときはこうする」という手順は[スキル](02-skills.md)に分けます。
- **同じことを 2 か所に書かない。** 直したときに片方だけ古いまま残ります。

## 育て方

エージェントが同じ間違いを 2 回したら、1 行足します。守らなくてよくなった行は消します。
