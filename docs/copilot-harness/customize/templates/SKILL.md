## 品質基準

- {{例: 変換後ファイルは必ず元ファイルと別名で保存し、元を消さない}}
- {{例: 「おそらく動く」と書かない。実行した結果だけを報告し、実行していない項目は「未実施」と書く}}

## 報告の形式

作業の最後に次の 5 項目で報告する。

- 変更・生成したファイル
- 実行したコマンドと結果(成功 / 失敗、要点の数値)
- 使った外部 API と根拠(版・場所)。無ければ「なし」
- 確認できなかったこと
