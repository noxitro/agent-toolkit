# 表データ集計 (table-summary)

## 目的
添付された表ファイルの中身を、集計スクリプトで正確に数えて報告する。数値は必ずスクリプトの出力から取り、暗算や推測で埋めない。

## 前提
- スクリプトのサンドボックスはインターネットにも社内ネットワークにも接続できない。扱えるのはチャットに添付されたファイルだけ。共有フォルダや SharePoint の URL を示されたら、ファイルを添付してもらう。
- 対応形式: .csv / .tsv / .txt (区切り文字は自動判定) と .xlsx / .xlsm。旧形式 .xls は不可 (.xlsx か CSV で保存し直してもらう)。

## 手順
1. **ファイルを探す**: `python3 scripts/locate_inputs.py --ext .csv,.tsv,.txt,.xlsx,.xlsm` を実行する。新しい順にパスが出る。見つからない (終了コード 1) ときは、ファイルを添付するよう利用者に頼んで止まる。複数あれば、利用者が名前を挙げたものか、最も新しいものを使い、どれを使ったかを回答に書く。
2. **Excel ならシートを確認**: `python3 scripts/table_summary.py <ファイル> --list-sheets`。依頼に合うシートを `--sheet <名前>` で選ぶ (既定は先頭シート)。
3. **まず全体を把握**: `python3 scripts/table_summary.py <ファイル> --profile --out profile.csv`。列名・推定型・件数を見て、依頼に出てくる言葉がどの列に当たるか決める。
4. **依頼に応じて集計**:
   - グループ集計: `--group-by 部署 --sum 金額 --count --out result.csv` (`--group-by` を 2 つ並べるとクロス集計、`--mean 列` で平均)
   - 絞り込み: `--filter "部署=営業" --filter "金額>=10000"` (演算子 `= != >= <= > <` と、部分一致の `~`。複数は AND)。絞り込みとグループ集計は同時に使える。
   - 月別・年別: `--group-by "日付:月" --sum 金額` (`:年` `:日` も可。期間の古い順に並ぶ)。期間を絞るときは `--filter "日付>=2026-04-01" --filter "日付<2026-07-01"`。
5. **出力を読む**: 標準出力の Markdown をそのまま根拠にする。「注意:」行 (数値として読めず除外した件数など) は必ず回答に含める。

## 回答の形
- 日本語で、最初に結論 (例: 「営業部の合計が最大で 1,234,000 円」) を 1〜3 行。
- 次にスクリプトが出した Markdown の表を貼る (省略行がある場合はその旨も)。
- `--out` で作った CSV をダウンロード用ファイルとして返す。UTF-8 (BOM 付き) なので Excel でそのまま開ける。
- 前提を明記する: 使ったファイルとシート、見出し行、絞り込み条件、除外した件数、列の解釈 (例: 「売上」を「金額」列と解釈)。

## エラー時
- スクリプトは利用者が直せる問題を `エラー: ...` (終了コード 2) で日本語表示する。内容をそのまま伝え、対処を案内する。
- 「文字コードを判定できませんでした」: Excel で「CSV UTF-8」として保存し直してもらうか、`--encoding cp932` などを試す。
- 「列「…」が見つかりません」: 表示された列一覧から正しい列名を選び直す。曖昧なら利用者に確認する。
- 見出しがずれている (タイトル行や空行がある) ときは `--header-row <行番号>` を指定する。
- 同じ処理で 2 回失敗したら、推測で数字を作らず、何が起きたかを説明して止まる。
