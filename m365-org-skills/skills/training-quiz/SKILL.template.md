# 研修資料から理解度テスト作成

## 目的

添付された研修資料の内容から、受講者の理解を確かめるテストを作る。**資料に書かれていることだけを問う**。ひっかけ問題は作らない。

## 入力

- 研修資料:.docx / .pptx / .pdf / .txt / .md(添付)、または貼り付けた本文
- 任意の指定(なければ既定値を使い、冒頭でその旨を伝える)
  - 問題数:既定 10問
  - 形式の内訳:既定 選択式 6・○× 3・記述 1
  - 難易度の内訳:既定 易 4・中 4・難 2
  - 出題範囲(章・スライド番号)

## 手順

1. **資料を探す**:`python3 scripts/locate_inputs.py --ext .docx,.pptx,.pdf,.txt,.md` を実行する。
   - 何もない → 「研修資料を添付するか、本文を貼り付けてください」と依頼して止まる。
   - .doc / .ppt(古い形式)→ 「.docx / .pptx で保存し直して添付してください」と伝える。
2. **本文を取り出す**:
   - .docx / .pptx / .txt / .md:`python3 scripts/extract_text.py <パス> --out material.txt` を実行し、`material.txt` を読む。各行に `[段落N]` `=== スライド N ===` `[行N]` の位置が付く。
   - .pdf、またはスクリプトが「未対応」(終了コード 3)を返した形式:エージェント自身がファイルを読む。位置は「p.N」(ページ)で表す。
   - 「テキストが見つかりません」の場合は、画像だけの資料の可能性を伝え、文字を含む形式での添付を依頼する。
3. **出題する箇所を選ぶ**:研修の目的に関わる重要事項(定義、手順、ルール、数値基準、注意点)を優先し、範囲が偏らないよう章・スライド全体から選ぶ。
4. **問題を作る**(下の「出題ルール」に従う)。
5. **検証して CSV にする**:問題を次の形の `quiz.json` に保存し、
   `python3 scripts/quiz_to_csv.py quiz.json --csv quiz.csv --forms-text quiz-forms.txt` を実行する。
   ```json
   {"title": "〇〇研修 理解度テスト", "questions": [
     {"type": "選択式", "difficulty": "易", "question": "…", "choices": ["…", "…", "…", "…"],
      "answer": "正解の選択肢の文言", "explanation": "…", "source": "スライド3"}]}
   ```
   `type` は 選択式 / ○× / 記述、`difficulty` は 易 / 中 / 難。○× の `answer` は ○ か ×、記述の `answer` は模範解答(採点の観点を含めてよい)。
   - エラーが出たら内容を直して再実行する(エラーのある間はファイルが作られない)。「注意」は該当問題を見直す。

## 出題ルール

- 正解と解説の根拠が資料内にあること。資料にない一般知識・推測・最新情報は問わない。`source` には根拠の位置(スライド番号・段落番号・ページ)を書く。
- 選択式は正解が1つだけ。誤答の選択肢は、資料内の別の内容や、ありがちな誤解に基づいて作り、もっともらしいが明確に誤りであるものにする。「上記すべて」「いずれでもない」は使わない。
- ○× は、資料の記述を1か所だけ変えた文を×の問題にする。○と×がおおむね半々になるようにする。
- 記述は、資料の内容を自分の言葉で説明させる問題にし、模範解答と採点の観点を書く。
- 二重否定、細かすぎる数字の暗記、文言の一字違いを問う問題、ひっかけ問題は作らない。
- 個人名・顧客名など、テストに載せるべきでない情報は問題に含めない。

## 出力

- チャット:日本語で、問題一覧(番号・形式・難易度・問題文・選択肢)を表示し、その後に「解答と解説」をまとめて示す(受講者に配る前に講師が確認できるよう分ける)。各解説に出典位置を付ける。
- ファイル:
  - `quiz.csv`:Excel で開ける UTF-8(BOM 付き)。列は「番号, 形式, 難易度, 問題文, 選択肢1〜選択肢N(N は4以上、使った最大数), 正解, 解説, 出典」。○× の選択肢欄は ○ / ×、記述は空欄。
  - `quiz-forms.txt`:問題文と a. b. c. の選択肢だけを並べたテキスト(正解は含まない)。Microsoft Forms の「クイック インポート」は Word / PDF から読み込むため、ユーザーが Forms で使う場合は、この内容でエージェント自身の文書作成機能を使って Word 文書を作り、Forms 側で読み込み後に正解を設定するよう案内する。
- Forms には CSV を直接取り込む機能はない。CSV は Excel での管理や、Forms への手入力の元データとして使うよう伝える。
