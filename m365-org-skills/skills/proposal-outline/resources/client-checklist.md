# 提案前に相手へ確認する事項

骨子作成時、未確認の項目だけを抜き出して「要確認一覧」に載せる。

## 目的・背景

- [ ] 今回の検討のきっかけ・目的
- [ ] 解決したい課題の優先順位
- [ ] 成功の基準(何がどうなれば成功か)

## 意思決定

- [ ] 決裁者と、検討に関わる部署・担当者
- [ ] 決裁の時期・社内手続き(稟議、比較検討の有無)
- [ ] 比較している他の選択肢(言える範囲で)

## 予算・条件

- [ ] 予算の有無・規模・確定時期
- [ ] 費用の考え方(初期/月額、資産計上の可否など)
- [ ] 必須の要件と、あれば望ましい要件
- [ ] セキュリティ・情報管理の社内基準

## 現状

- [ ] 対象の業務・人数・件数・頻度
- [ ] 現在使っているシステム・ツールと連携の必要性
- [ ] 現状の作業時間・コスト(効果試算に使う)

## スケジュール・体制

- [ ] 導入・開始の希望時期と、その理由
- [ ] 相手側で対応できる体制(窓口、作業できる人)
- [ ] 繁忙期など避けたい時期

## 提案の進め方

- [ ] 提案の形式(資料提出・プレゼン・デモ)と持ち時間
- [ ] 提出期限と提出先
