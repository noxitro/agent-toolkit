# 1枚企画書

社内の企画・稟議の添付・上長への相談用。A4 1枚(スライド1枚)に収める。各項目は2〜3行まで。

| 項目 | 書くこと |
|---|---|
| 企画名 | 何をするかが一目で分かる名前 |
| 提案者・日付 | 部署・氏名・提出日 |
| 背景・課題 | なぜ今これが必要か。現状の問題を数字で(根拠がなければ要確認) |
| 目的・ゴール | 実施後にどうなっていれば成功か(測れる形で) |
| 実施内容 | 何を・誰が・どうやって。箇条書き3〜5個 |
| 期待効果 | 定量(時間・コスト)と定性。算出根拠を1行で |
| 費用・必要なリソース | 金額、人員、工数、使うツール。未確定なら要確認 |
| スケジュール | 開始〜完了までの主要な節目(3〜4個) |
| リスク・懸念 | 主なもの1〜2個と対策 |
| 決めてほしいこと | 承認、予算確保、担当者のアサインなど、読み手に求める判断 |
