# スライドアウトラインの書式

Copilot in PowerPoint に渡す下書き。1スライド = 1ブロックで、見出しレベルをそろえる(人が読んでも、Copilot に渡してもスライドの区切りが分かるように)。

```
# {提案タイトル}

## スライド1:{スライドタイトル}
- {要点1(1行・40字以内)}
- {要点2}
- {要点3}
発表者ノート:{このスライドで話すこと。2〜4文。根拠や補足、相手への問いかけ}

## スライド2:{スライドタイトル}
- …
発表者ノート:…
```

## 書き方

- 要点は1スライド3〜5個。文ではなく短い句で書く。
- 数字には根拠を添える。根拠がないものは「【要確認】」と書く(PowerPoint 上でも目立つように)。
- Web 検索で得た情報は、要点の末尾か発表者ノートに「(出典:サイト名 URL、YYYY/MM/DD 確認)」と書く。
- 図にしたい箇所は「[図:現状と導入後の業務フロー比較]」のように指示を書く。
- 使い方(推奨):このアウトラインを Word 文書として保存し、PowerPoint の Copilot で新しいプレゼンテーションを作成するときにそのファイルを参照させる(Copilot in PowerPoint は Word などのファイルを参照してプレゼンテーションを作成できる)。
- 短いアウトラインなら Copilot のプロンプト欄に直接貼り付けてもよい。プロンプト欄には文字数の上限があると報告されているため、長い場合は Word 経由にする。
