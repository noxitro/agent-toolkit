次の章立てで、Markdown ファイル 1 本として出力してください。章の順序と見出しは変えないでください。

1. `# <ガイドライン名>`
2. `## 概要` — 目的と対象読者を 3〜5 文で。
3. `## 詳細` — 守るべきルールと背景。必要なら `###` で小見出しを切る。
4. `## 手順` — 番号付きリスト。各ステップに確認方法を添える。
5. `## 関連リンク` — 「含めたページ」の一覧にある URL だけを、ページ名付きで列挙する。
6. 末尾に `元ページの取得日: <このコンテキストの最も古い取得日>` を 1 行で書く。

禁止事項:

- 「含めたページ」に無い URL を書かない。
- 元ページに無い手順・数値・担当者を補わない。不明な点は `要確認: <何が不明か>` と書く。
- 章の追加・削除・並べ替えをしない。

出力の前に、次を自分で確かめてから出力してください。

- [ ] 6 つの要素がこの順に揃っている。
- [ ] 「手順」の各ステップについて、根拠になった元ページを挙げられる。
- [ ] 「関連リンク」の URL がすべて「含めたページ」の一覧にある。
- [ ] `要確認:` が付いた箇所は、何が不明かが読んで分かる。
